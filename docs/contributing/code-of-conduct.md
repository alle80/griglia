# Code of conduct

Griglia adopts the [Contributor Covenant](https://www.contributor-covenant.org) version 2.1, unmodified except
for the address to write to. The text that counts is
[`CODE_OF_CONDUCT.md`](https://github.com/alle80/griglia/blob/master/CODE_OF_CONDUCT.md) at the root of the
repository — GitHub reads it from there and shows it in the community profile — and it is reproduced in full
at the bottom of this page.

This page is the part a document written for every project cannot say: what the covenant means in a project
with one maintainer, where it applies, and what actually happens when somebody reports something.

## Why a standard text

Writing a code of conduct from scratch would have produced a page nobody recognises, and a contributor
deciding whether to open a pull request should not have to read a bespoke set of rules to find out whether
they are welcome. The Contributor Covenant is the text most people in this ecosystem already know, it has
[official translations](https://www.contributor-covenant.org/translations) in dozens of languages, and it is
the one GitHub detects. Adopting it verbatim is the point: no surprises hidden in a reworded clause.

## Where it applies

| Space | Covered |
|---|---|
| Issues, pull requests, review and commit threads on [github.com/alle80/griglia](https://github.com/alle80/griglia) | Yes |
| The documentation site and anything published from this repository | Yes |
| Anywhere somebody is speaking for Griglia — an official account, a talk, a demo | Yes |
| Your own board, your own fork, your own instance | No: that is your space, and your host application's rules |

Griglia is a package people run privately: the board on your machine, the tasks you write for your agent and
the way you talk to it are yours. This document is about the shared spaces of the project.

## What it means in a review

Reviews here are direct, and that does not change. "This belongs in the host application", "this needs a test
that fails without it" and "no, for the reason already written in the issue" are normal answers — see
[how we talk to each other](contributing.md#how-we-talk-to-each-other). Being told your change is out of scope
is not a conduct problem, and neither is a short reply from a maintainer working on personal time.

What is a conduct problem is the person rather than the code: snark at somebody's setup, their English, their
experience or the fact that they used an agent; sexualised language or attention; harassment in public or in
private; publishing somebody's private information. The list in the covenant is not decoration — it is the
list that gets applied.

## Reporting

E-mail the maintainer at the address published in
[`composer.json`](https://github.com/alle80/griglia/blob/master/composer.json), the same one on the
[@alle80](https://github.com/alle80) GitHub profile. Useful in the message: links to what happened, when it
happened, and whether it is still going on.

What happens next:

- the report is read only by the maintainer, and gets an answer within **three working days**;
- the person who reported is never named in public, and neither is the content of the report;
- the response follows the four steps of the covenant — correction, warning, temporary ban, permanent ban —
  chosen for the impact, not for who is involved;
- moderation on GitHub (editing, hiding or locking a thread, blocking an account) is explained when it is not
  obvious why it happened.

If the report is about the maintainer, say so: with one person in charge there is nobody to escalate to, and
the honest answer is that it will be handled in the open rather than pretending a committee exists.

!!! warning "A vulnerability is not a conduct report"
    Security problems go through [SECURITY.md](https://github.com/alle80/griglia/blob/master/SECURITY.md) —
    private e-mail or GitHub's private reporting, never a public issue. See
    [Security](../operations/security.md).

## In other languages

The covenant has [official translations](https://www.contributor-covenant.org/translations), including
[Italian](https://www.contributor-covenant.org/it/version/2/1/code_of_conduct/). They are all the same
document: in a dispute the English text in the repository is the one that decides, because it is the one under
version control.
